## 🌐 GitHub Pages Deployment

This repository is configured for automatic deployment to GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`).

### To Enable GitHub Pages:
1. Go to your repository **Settings → Pages**.
2. Under **Build and deployment → Source**, select **Deploy from a branch**.
3. Select **`gh-pages`** as the branch and `/ (root)` folder, then click **Save**.
4. Under **Custom domain**, enter `renusreechittella.com` and check **Enforce HTTPS**.
